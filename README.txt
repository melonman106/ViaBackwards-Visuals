ViaBackportVisuals — 26.2 CLIENT PACK

Install this pack locally on your 26.2 / Eagler client.

Designed for the ViaBackportVisuals Fabric 26.3 server mod.

Includes:
- 16 wool stair appearances
- 16 wool slab appearances
- Straw Bed placeholder appearance

This is a CLIENT-SIDE pack. It does not depend on a server resource pack.

IMPORTANT:
The server mod currently maps new blocks onto existing 26.2 placeholder blocks.
Therefore the corresponding placeholder blocks will also use these visuals.

The current server log reports 1200 wool stair states and 96 wool slab states.
Gray Wool Stairs currently have no matching placeholder states, so gray stairs
will remain unresolved until the server-side mapping is corrected.

The pack format is 88.0 for Minecraft 26.2.
